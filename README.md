# Sistema de Gestión de Mantenimiento – Almarena La Reserva

## Descripción del proyecto

El presente proyecto tiene como objetivo desarrollar un módulo de gestión de mantenimiento y seguimiento del estado de los departamentos de Almarena La Reserva.

El sistema busca centralizar las solicitudes de mantenimiento, facilitar la asignación de tareas al personal disponible, registrar las intervenciones realizadas y mantener actualizada la información sobre el estado operativo de cada departamento.

Además, permitirá conservar un historial de las intervenciones para identificar problemas recurrentes y generar información que facilite la planificación y la toma de decisiones.

## Objetivos principales

- Centralizar las solicitudes de mantenimiento.
- Mejorar la coordinación entre las áreas involucradas.
- Registrar y realizar el seguimiento de las intervenciones.
- Mantener actualizado el estado de los departamentos.
- Generar información histórica para facilitar la toma de decisiones.

## Declaración de Uso de Inteligencia Artificial

Durante el desarrollo del presente proyecto se utilizaron herramientas de inteligencia artificial, principalmente ChatGPT, como apoyo para la organización, estructuración y revisión de la documentación técnica.

La asistencia de estas herramientas se utilizó en distintas etapas del trabajo, mediante consultas y prompts orientados a:

- Estructurar la documentación del proyecto y organizar sus diferentes entregas.
- Proponer y revisar el modelado de procesos mediante notación BPMN.
- Organizar las entidades, atributos y relaciones del diccionario de datos.
- Mejorar la redacción de las historias de usuario y los objetivos del sistema.
- Orientar la organización del repositorio GitHub y la gestión de ramas y Pull Requests.
- Proponer indicadores de control y estándares de desempeño para la auditoría técnica.

**Revisión crítica y correcciones humanas**

Los resultados proporcionados por las herramientas de IA fueron utilizados como propuestas de trabajo y no incorporados de manera automática. El autor realizó revisiones y correcciones para asegurar que la documentación representara adecuadamente las características y necesidades reales de Almarena La Reserva.

Entre las principales intervenciones humanas se destacan:

- La validación y corrección de los procesos operativos a partir del conocimiento directo de la organización.
- La revisión de las relaciones jerárquicas y funcionales del organigrama.
- La definición y ajuste de las entidades, atributos y relaciones del diccionario de datos.
- La diferenciación entre los procedimientos actuales de la organización y los comportamientos propuestos para el futuro sistema.
- La revisión de los diagramas, indicadores y criterios de control para mantener su coherencia con los objetivos del proyecto.

**Responsabilidad sobre el trabajo**

La utilización de inteligencia artificial tuvo un carácter complementario y de asistencia. Las decisiones finales, la selección de las propuestas, las correcciones, la validación de la información y la elaboración definitiva de los entregables son responsabilidad del autor del proyecto.
